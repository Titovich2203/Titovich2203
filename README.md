<summary>The five stages as text</summary>

1. **Transcribe** — Whisper, served by Groq · speech to text
2. **Direct** — Claude LLM · cuts, pacing, creative calls
3. **Place** — vision model on ONNX runtime · adaptive overlay placement
4. **Generate** — Higgsfield · image → video, deterministic cache
5. **Render** — async workers · multi-tenant isolation

Retrieval layer: PostgreSQL · pgvector · HNSW index — grounds every stage above.
